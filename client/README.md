# PrepPilot client

The PrepPilot web client is built with React, Vite, Tailwind CSS, Redux Toolkit, React Router, Firebase Authentication, and Axios.

For complete project setup, environment variables, API configuration, and test instructions, see the [project README](../README.md).

Start the client from this directory:

```powershell
npm install
npm run dev
```

The default local client URL is `http://localhost:5173`. Run `npm run lint` and `npm run build` to validate the client.
